# Workout Routine Mobile App & Tracker 💪

A clean, responsive workout routine tracker and native Android application designed to display exercise animations (GIFs), sets, reps, rest intervals, and an interactive rest timer.

## ✨ Features

- **Multi-Routine Support**: Easily toggle between routines:
  - **Schedule 02**: 10 exercises focused on full-body / hypertrophy.
  - **Schedule 03**: 11 exercises focused on compound and isolation movements.
- **Embedded Offline GIF Demonstrations**: All exercise GIFs work completely offline.
- **Set & Rep Counter with Rest Timer**: Integrated countdown timer (with pause/reset and vibration alert) between sets.
- **Touch Gesture Navigation**: Swipe left for Next exercise, swipe right for Previous exercise.
- **Multi-Platform**:
  - **Native Android App**: Pre-built [`WorkoutRoutine.apk`](./WorkoutRoutine.apk) ready to install on Android phones.
  - **Progressive Web App (PWA)**: [`index.html`](./index.html) can be opened in mobile browsers or installed directly to your home screen.

## 📱 Installation on Android

1. Download [`WorkoutRoutine.apk`](./WorkoutRoutine.apk) onto your Android device.
2. Tap the APK file and select **Install** (enable "Install unknown apps" in Settings if prompted).
3. Open the **Workout Routine** app.

## 🌐 Running the Web Version

Simply open [`index.html`](./index.html) in any modern web browser or mobile browser.
